Task 1: Introduction to IoT & Device Communication 
1. IoT Architecture 
The architecture of an Internet of Things (IoT) system is generally broken down into three 
fundamental layers: 
Devices (Perception/Edge Layer): This is the physical layer where data originates. It consists of 
sensors (which gather data like temperature, distance, or motion) and actuators (which perform 
physical actions like turning a motor or flipping a switch). Microcontrollers, such as the 
ESP8266, ESP32, or Arduino UNO, act as the "brains" at this level, reading sensor data and 
controlling the actuators. 
Network (Connectivity Layer): This layer is responsible for transporting the data collected by 
the devices. It utilizes communication protocols (like Wi-Fi, Bluetooth, Zigbee, or LoRaWAN) 
and messaging protocols (like MQTT or HTTP) to securely transmit information from the edge 
devices to the internet. Gateways are often used here to bridge local sensor networks to the wider 
web. 
Cloud (Processing/Application Layer): Once the data reaches the internet, it is hosted on cloud 
service platforms (such as Google Firebase, Arduino IoT Cloud, or Blynk). The cloud layer 
stores, processes, and analyzes the massive amounts of data generated by the edge devices. It is 
also where the user interface (web or mobile app) is hosted, allowing humans to interact with the 
IoT system, view dashboards, and send commands back down to the devices. 
2. Real-World IoT Use Cases 
IoT is transforming both everyday life and industrial operations. Here are a few practical use 
cases: 
Smart Pet Care Systems: A smart pet bowl monitor can utilize ultrasonic or weight sensors 
connected to a microcontroller to track pet food levels. This data is synced to a cloud database, 
allowing owners to monitor feeding habits remotely via an app and receive alerts when food is 
running low. 
Automated Aquaculture & Agriculture: An IoT-enabled fish feeder can be designed using 
Wi-Fi-enabled microcontrollers and servo motors. Users can set specific feeding schedules or 
trigger the feeder remotely through a dashboard, ensuring consistent care without requiring 
physical presence. 
Smart Home Automation: Devices like smart thermostats and lighting systems learn user 
preferences and adjust settings automatically to optimize energy consumption and comfort. 
Industrial IoT (IIoT): Manufacturing plants use sensors on factory equipment to monitor 
vibration and temperature. The system analyzes this data to predict when a machine is likely to 
fail, allowing for "predictive maintenance" before a costly breakdown occurs. 
3. Data Flow in an IoT System 
The communication between devices in an IoT ecosystem follows a continuous, cyclical data 
flow: 
Collection: A sensor detects a physical parameter in the real world (e.g., an ultrasonic sensor 
measures the distance to the top of the food in a pet bowl). 
Transmission: The local microcontroller formats this raw data and transmits it over a network 
(e.g., via Wi-Fi using the MQTT protocol) to a cloud server. 
Processing & Storage: The cloud platform receives the payload, stores the data in a database, 
and applies any necessary logic or analytics (e.g., calculating that the food level is below 10%). 
Action & Feedback: The system triggers a response based on the processed data. This could be 
sending a push notification to the user's mobile phone, or sending a command back down the 
network to an actuator (e.g., signaling a servo motor to dispense more food).
